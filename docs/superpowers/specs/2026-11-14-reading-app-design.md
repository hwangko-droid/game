# 고1 진로 독서 앱 — 설계 문서

작성일: 2026-11-14 · 상태: 승인됨

## 1. 왜 만드는가

호남고등학교 1학년 **진로 시간** 독서 프로그램용 앱이다. 학생은 앱에서 자기 취향·진로에 맞는 책을 고르고, 읽고, 독후감을 써서 올린다. 독후감은 같은 학년 학생들끼리 **실명으로** 공개된다.

핵심 의도(선생님 말씀): "비슷한 진로를 가진 친구들이 어떤 책을 보고 있는지, 어떤 감상을 남겼는지, 책을 왜 추천하는지가 드러나면 좋겠다. 같은 진로 학생들끼리 뭉치고 이야기할 수 있으면 좋겠다."

그래서 이 앱은 독후감 보관함이 아니라 **같은 진로 친구를 찾는 지도**다. 친구의 독후감이 다음 친구의 추천서가 된다.

## 2. 목표 / 비목표 / 반(反)목표

**목표**
- 학생이 진로 분야를 고르면 그 분야 친구들이 읽은 책·감상·추천 이유가 먼저 보인다.
- 학생이 독후감(감상 + 추천 이유 한 줄 + 친구에게 묻는 질문 한 줄)을 올린다.
- 같은 학년 학생들이 독후감에 실명으로 댓글을 단다.
- 서울대 추천도서는 '봉우리', 진입 쉬운 책은 '징검다리'로 함께 보여 준다.
- 책마다 "우리 도서관에서 찾기" 버튼으로 학교 도서관(read365) 검색으로 이어진다.
- 선생님은 구글 시트에서 전체 독후감을 실명으로 보고 학생부 정리에 쓴다.

**비목표**
- 자동 추천 알고리즘·AI 추천 (이번 버전 없음)
- 도서관 소장 여부 자동 조회 (read365 구조 미확인)
- 진로 분야별 자유 게시판 (대화는 독후감 댓글에만)
- 점수·순위·좋아요 경쟁

**반목표 (돌아가도 실패인 경우)**
- 학생 실명과 글이 학교 구글 밖(외부 서버)으로 나간다.
- 같은 학년이 아닌 사람이 링크만으로 실명 글을 읽는다.
- 서울대 목록만 덩그러니 있어 학생이 "학생부용 책"만 고른다.

## 3. 제약

- 학생·교사 계정: 전북교육청 구글 워크스페이스 `@ai.jbedu.kr` (교육청 SSO 로그인).
- 구글 교육용 계정의 만 18세 미만 학생은 외부(서드파티) 앱 구글 로그인이 기본 차단 → 외부 앱 불가.
- 기기: 전북 1인 1기기(태블릿) 가정 → 태블릿·휴대폰 화면 우선.
- 선생님은 개발자가 아니다. 배포는 "복사 → 붙여넣기 → 배포 버튼" 수준이어야 한다.
- 무료.

## 4. 고려한 방식 (Approaches)

| 방식 | 장점 | 단점 | 결정 |
|---|---|---|---|
| **① 구글 앱스 스크립트 웹앱 + 구글 시트** | 학교 계정 자동 로그인, 미성년 외부앱 차단 무관, 데이터가 선생님 드라이브에 머묾, 시트로 바로 관리 | 화면 반응 약간 느림, 동시 접속 수십 명 이상이면 지연 | **선택** |
| ② 구글 설문지 제출 + 보기 화면 | 가장 빠름 | 댓글·진로 지도 구현 어려움 → "이야기" 약화 | 제외 |
| ③ 외부 서버 독립 웹앱 | 화면 가장 매끄러움 | 미성년 로그인 차단으로 교육청 승인 필요, 실명이 외부 저장 | 제외 |

선생님이 ①을 선택함 (2026-11-14).

## 5. 선생님이 정한 것

- 대상: 고1, 진로 시간.
- 독후감은 같은 학년끼리 **실명 공개**.
- 같은 진로 친구끼리 무엇을 읽고 왜 추천하는지 드러나게.
- 같은 진로끼리 이야기할 수 있게.
- 서울대 추천도서 포함.
- 학교 도서관 검색 링크: `https://read365.edunet.net/PureScreen/SchoolSearch?schoolName=호남고등학교&provCode=P10&neisCode=P100000464`
- 구현 방식: 앱스 스크립트 웹앱.

## 6. 설계

### 6.1 구성
- 구글 시트 1개(선생님 드라이브) = 데이터베이스. 탭:
  - `학생` : 이메일, 이름, 반, 번호, 진로분야, 최초접속일
  - `도서` : 도서ID, 제목, 저자, 구분(봉우리/징검다리/학생추가), 진로분야(복수, 쉼표), 연결봉우리ID, 한줄소개
  - `독후감` : 독후감ID, 이메일, 도서ID, 감상, 추천대상, 추천이유, 질문, 작성일, 수정일, 숨김(TRUE/FALSE)
  - `댓글` : 댓글ID, 독후감ID, 이메일, 내용, 작성일, 숨김
  - `설정` : 진로분야 목록, 학년도, 입장 허용 방식, 도서관 링크
- 앱스 스크립트 웹앱(`Code.gs` + `index.html`), 시트에 묶인(컨테이너 바인딩) 스크립트.
- 배포: "실행: 나(선생님)", "액세스: ai.jbedu.kr 도메인 사용자". 사용자 식별은 `Session.getActiveUser().getEmail()`.

### 6.2 접근 제한 (실명 보호)
도메인 제한만으로는 **전북 전체 학생·교사**가 링크로 들어올 수 있다(현실적 경로: 단톡방 링크 유출). 그래서 한 겹 더 막는다.
- **입장 코드 (기본: 켜짐)**: 처음 접속 시 선생님이 수업에서 알려 준 코드를 입력해야 `학생` 탭에 등록됨. 등록 후에는 다시 묻지 않음.
- `설정` 탭의 `입장코드사용`(TRUE/FALSE)과 `입장코드` 칸으로 켜고 끄거나 코드를 바꿀 수 있다.
- 명단 방식은 이메일 수집 부담 대비 이득이 작아 제외 (선생님 결정, 2026-11-14).
- 캡처 유출은 기술로 못 막으므로 첫 시간에 "친구의 글은 앱 안에서만 읽는다" 약속을 정하는 것을 운영 권장사항으로 둔다.
- 선생님 이메일(관리자)은 `설정`에 등록, 관리자 화면 접근.
- 미허용 사용자는 "이 앱은 호남고 1학년 진로 수업용입니다" 화면만 본다. 어떤 학생 정보도 내려보내지 않는다(서버에서 차단).

### 6.3 첫 접속
입장 코드(켜져 있을 때) → 반·번호·이름·진로분야 입력. 진로분야는 `설정`의 고정 목록에서 1개 선택, 나중에 바꿀 수 있음.

진로분야 기본값 (선생님이 시트에서 수정 가능):
의약·보건 / 공학·IT / 자연과학 / 교육 / 법·행정·정치 / 경영·경제 / 인문·언어 / 사회·심리 / 미디어·예술 / 아직 모르겠음

### 6.4 화면 (태블릿 세로 기준, 하단 탭 4개)

1. **우리 진로** (첫 화면)
   - 내 진로분야 친구 목록: 이름·반, 읽은 책 제목들.
   - 이 분야에서 최근 올라온 독후감 카드 (추천이유 한 줄이 가장 크게).
   - 다른 분야로 바꿔 보기 드롭다운.
2. **책 찾기**
   - 진로분야 필터 + 제목 검색.
   - 책 카드: 제목·저자·구분 배지(봉우리/징검다리), "○○ 분야 친구 N명이 읽음", 대표 추천이유 1개, 연결된 봉우리/징검다리.
   - 버튼: "우리 도서관에서 찾기"(제목을 클립보드에 복사 후 도서관 검색 페이지 새 창), "이 책으로 독후감 쓰기".
   - 목록에 없는 책은 학생이 직접 추가 가능(구분=학생추가).
3. **독후감 쓰기**
   - 책 선택 → 감상(본문) / "이 책을 ___한 친구에게 권한다" / "왜냐하면 ___" / "같은 진로 친구에게 묻고 싶은 것 한 줄".
   - 감상 최소 글자 수: `설정`에서 지정(기본 300자). 임시저장(브라우저).
   - 내 글은 수정 가능, 삭제는 선생님만.
4. **내 기록**: 내가 쓴 독후감, 내 글에 달린 댓글.

**독후감 상세**: 본문, 추천이유, 질문(강조), 댓글 목록(실명·반), 댓글 입력.

**관리자(선생님) 화면**: 반별 제출 현황(누가 몇 편), 글·댓글 숨김 토글. 세부 열람·학생부 정리는 시트에서 직접.

### 6.5 도서 초기 데이터
- 봉우리: 서울대 권장도서 100선 중 고1 진로와 연결하기 좋은 책 일부.
- 징검다리: 각 진로분야별로 고1이 읽을 만한 교양서, 봉우리와 연결.
- 초기 목록은 빌더가 실재하는 책·저자만으로 작성하고, **선생님이 시트에서 검토·수정**한다. (확실하지 않은 서지는 넣지 않음.)

### 6.6 운영 가정
- 한 번에 한 반(약 30명)이 동시에 쓰는 수준. 동시 쓰기 충돌은 `LockService`로 처리.
- 학년도가 바뀌면 시트를 복사해 새로 시작.

## 7. 빌더 재량으로 둔 것 (제 판단, 선생님 확인 필요 시 수정)
- 첫 접속 시 학생이 반·번호·이름을 직접 입력 (구글 계정 이름 자동 조회는 추가 권한이 필요해 생략).
- 도서관 버튼은 read365 검색어 파라미터가 확인되지 않아 "제목 복사 + 검색 페이지 열기" 방식.
- 학생의 독후감 삭제 불가(선생님만 숨김) — 과제 기록 보존.
- 좋아요·순위 없음.
- 화면 디자인, 코드 구조, 시트 열 순서 세부.
