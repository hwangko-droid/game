# 우리 진로 책장 — 설치·운영 안내 (선생님용)

고1 진로 시간 독서 앱입니다. 학생은 **구글 로그인 없이** 비밀번호(기본 `2027`)와 반·번호·이름으로 들어와 책을 고르고, 독후감을 올리고, 같은 진로 친구의 글에 댓글을 답니다. 모든 데이터는 **선생님 구글 드라이브의 시트 한 개**에 저장됩니다.

붙여 넣을 파일은 두 개입니다: `dist/Code.gs`, `dist/index.html`

---

## 1. 처음 설치 (약 10분, PC 크롬 권장)

1. 선생님 **honam.hs.kr 계정**의 구글 드라이브에서 시트 **`우리 진로 책장 2026`**을 엽니다. (없으면 새 구글 시트를 만들고 이 이름을 붙입니다.)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs`를 열고 안의 내용을 모두 지운 뒤, `dist/Code.gs` 내용 **전체**를 붙여 넣습니다.
4. 왼쪽 **파일 옆 `+` → HTML**을 누르고 이름을 `index`로 정합니다(`.html`은 자동으로 붙음). 안의 내용을 지우고 `dist/index.html` 내용 전체를 붙여 넣습니다.
5. 💾 저장(Ctrl+S).
6. 위쪽 함수 선택 칸에서 **`초기설정`**을 고르고 **▶ 실행**을 누릅니다.
   - "권한 검토 필요" 창이 뜨면 → 내 계정 선택 → (경고가 나오면 "고급 → 안전하지 않은 페이지로 이동") → 허용. 선생님이 직접 만든 스크립트라서 나오는 안내입니다.
   - 시트로 돌아가면 `학생 · 도서 · 독후감 · 댓글 · 설정 · 질문` 탭이 생겨 있습니다.
   - `설정` 탭의 **관리자비밀번호**(`관리`+숫자 4자리)를 확인해 두세요. 선생님이 앱에 들어갈 때 씁니다.
7. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 설명: `2026 1학년`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ("Google 계정이 있는 모든 사용자"나 "honam.hs.kr 내 모든 사용자"가 아니라 그냥 **모든 사용자**)
   - 배포 → 나오는 **웹 앱 URL**을 복사합니다. 이것이 학생에게 줄 링크입니다.
8. **먼저 시험해 보기**: 로그인하지 않은 휴대폰 브라우저(시크릿 창)로 링크를 열어 `2027` + 반·번호·이름으로 들어가 독후감 1편까지 올려 봅니다.
   - "모든 사용자" 항목이 없으면 학교 구글 관리 설정에서 막혀 있는 것입니다. 학교 구글 관리자(정보부)에게 "Apps Script 웹앱을 모든 사용자에게 배포"가 가능한지 문의해 주세요.

## 학생이 들어오는 방법

- 링크 → **비밀번호 `2027`**, 이름, 반, 번호, 진로 분야 → 들어가기.
- 처음 들어오면 **"나를 알려 주세요"** 화면에서 '요즘 궁금한 질문'을 1~3개, 독서량(가볍게/보통/깊게)을 고릅니다. 이걸로 '책 찾기' 맨 위에 **나에게 맞는 책**이 나옵니다. '내 기록'에서 언제든 바꿀 수 있습니다.
- 한 번 들어오면 그 기기가 기억합니다. 다른 기기에서는 같은 반·번호·이름으로 다시 들어오면 같은 사람으로 이어집니다.
- 같은 반·번호에 다른 이름을 넣으면 들어갈 수 없습니다(친구 번호 가로채기 방지). 이름을 잘못 넣고 등록해 버린 학생은 `학생` 탭에서 그 줄의 이름을 고쳐 주세요.
- 시트의 `학생ID`는 `반-번호`(예: `2-07`)입니다. 독후감·댓글 탭에도 이 ID로 기록됩니다.
- **선생님**은 비밀번호 칸에 **관리자비밀번호**만 넣고 들어가기를 누르면 됩니다(이름·반·번호 비워도 됨).
- 공용 기기라면 '내 기록' 맨 아래 **이 기기에서 나가기**를 눌러 주세요.
- ⚠️ `학생` 탭의 `접속키`는 학생별 열쇠입니다. 다른 사람에게 보여 주지 마세요.

## 2. `설정` 탭

| 키 | 뜻 | 기본값 |
|---|---|---|
| 진로분야목록 | 쉼표로 구분한 진로 분야 | 의약·보건,공학·IT,… |
| 입장코드사용 | 비밀번호 필요 여부. **FALSE라고 적을 때만** 꺼짐(빈칸·오타는 켜진 것으로 봄) | TRUE |
| 입장코드 | 학생 비밀번호 | `2027` |
| 감상최소글자 | 독후감 감상 최소 글자 수 | 300 |
| 관리자비밀번호 | 선생님이 관리 화면으로 들어갈 때 쓰는 비밀번호 | `관리`+숫자 4자리 (자동 생성) |
| 도서관링크 | "우리 도서관에서 찾기" 버튼 주소. 버튼을 누르면 이 주소로 그 책 제목을 바로 검색합니다 | 호남고 read365 검색 |
| 학년도 | 기록용 | 2026 |

- 값만 바꾸면 바로 반영됩니다(재배포 필요 없음).
- 진로 분야 이름을 바꾸면, 이미 그 이름을 고른 학생은 `학생` 탭에서 함께 고쳐 주세요.

## 3. `도서` 탭

- 처음에 61권이 들어 있습니다: **봉우리**(서울대 권장도서) 9권, **징검다리** 52권(그중 '가볍게' 27권).
- 앱을 새로 고친 뒤 `초기설정`을 **다시 실행하면**, 시트에 없는 기본 책·질문만 더해집니다. 선생님이 고친 내용은 그대로 남습니다. (기본 책을 지웠다면 다시 실행할 때 되살아나니, 지우는 대신 `진로분야`·`질문` 칸을 비워 두세요.)
- ✅ **확인해 주세요**: `출처`가 "서울대 권장도서 100선"인 9권(코스모스, 부분과 전체, 침묵의 봄, 과학혁명의 구조, 군주론, 국부론, 광장, 난장이가 쏘아올린 작은 공, 열하일기)은 서울대 공식 목록과 대조하지 못했습니다. 공식 목록과 맞는지 확인하고, 다르면 `출처`를 고치거나 지워 주세요.
- `한줄소개`는 비어 있습니다. 채우면 책 카드에 보입니다.
- 책 추가: 맨 아래 행에 `도서ID`(겹치지 않게, 예: P10, B14), 제목, 저자, 구분(`봉우리`/`징검다리`), 진로분야(쉼표로 여러 개), 연결봉우리ID(징검다리일 때 이어지는 봉우리의 ID)를 적습니다.
- 학생이 앱에서 추가한 책은 구분이 `학생추가`로 들어옵니다.

## 3-1. `질문` 탭 — 학생이 고르는 '요즘 궁금한 질문'

- 처음에 14개가 들어 있습니다(제가 만든 초안). 문장을 고치거나, 맨 아래에 `Q15`, `질문 문장`처럼 더할 수 있습니다.
- 책과 질문의 연결은 `도서` 탭의 **`질문`** 열(예: `Q01,Q06`)에 적습니다. 질문을 새로 만들면 어울리는 책의 이 칸에도 ID를 넣어 주세요. 책이 하나도 연결되지 않은 질문은 추천에 영향이 없습니다.
- `도서` 탭의 **`난이도`** 열(`가볍게`/`보통`/`깊게`)은 학생의 독서량과 맞춰 볼 때 씁니다. 처음 값은 제 초안입니다.
- 추천 점수: 고른 질문과 겹치면 +3(질문마다), 진로가 맞으면 +1, 난이도가 독서량과 같으면 +1, 두 단계 차이(가볍게↔깊게)면 −1. 이미 독후감을 쓴 책은 빠지고, 최대 6권을 보여 줍니다.

## 4. 수업 운영

- **첫 시간 권장**: "친구의 글은 이 앱 안에서만 읽는다(캡처해서 밖으로 보내지 않는다)" 약속을 학생들과 함께 정해 주세요. 실명 공개를 지켜 주는 건 접속 제한보다 이 약속입니다.
- 비밀번호(2027)는 칠판에 적어 주세요.
- 오른쪽 위 **관리** 버튼: 반별로 누가 독후감·댓글을 몇 편 썼는지 보입니다.
- 부적절한 글·댓글: 해당 독후감 화면의 **숨기기** 버튼. 학생들에게서는 사라지고, 시트에는 `숨김=TRUE`로 남습니다(삭제 아님). **보이기**로 되돌릴 수 있습니다.
- 학생은 자기 글을 **고치기**만 할 수 있고 지울 수는 없습니다.
- 학생은 등록 후 **진로만** 바꿀 수 있습니다('내 기록'). 이름·반·번호는 선생님이 `학생` 탭에서 고칩니다. 반·번호를 고칠 때는 `학생ID`도 함께 고치고, 그 학생의 독후감·댓글 탭 `학생ID`도 같이 바꿔야 합니다.

## 5. 학생부 정리

- `독후감` 탭에 모든 글이 `학생ID`(반-번호)·작성일과 함께 있습니다. 데이터 → 필터 만들기로 학생ID별로 거르세요.

## 6. 코드를 고친 뒤

- Apps Script에서 코드를 바꾸면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 학생 화면에 반영됩니다. 링크는 그대로입니다.

## 7. 새 학년도

- 시트 파일을 **사본 만들기** → 사본의 `학생·독후감·댓글` 탭에서 2행부터 지우기 → `설정`의 학년도·입장코드 바꾸기 → 사본에서 Apps Script를 열어 **새 배포** → 새 링크를 학생에게 배포.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 학생이 "구글 로그인" 화면을 봄 | 배포의 액세스 권한이 "모든 사용자"인지 |
| "시트 탭이 없습니다" | `초기설정`을 실행했는지 |
| 고친 내용이 안 보임 | 새 버전으로 배포했는지 |
| "이미 다른 이름으로 등록된 번호" | `학생` 탭에서 그 번호의 이름 확인 |
| 여러 반이 동시에 쓰면 느림 | 정상입니다. 한 번에 한두 반 정도가 쾌적합니다 |
